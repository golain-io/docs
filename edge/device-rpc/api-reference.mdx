Device RPC uses the same interactive OpenAPI playground as Projects and Devices. Open any endpoint in the **Device RPC** sidebar below (or under **API Reference → Device RPC**) to send live requests.

## Two hosts

| Surface | Playground server | Routes |
|---------|-------------------|--------|
| **Management API** | `https://api.ilyama.golain.io/core/api/v1` | List services, reflect, descriptors, audit, poll queued calls |
| **RPC host** | `https://rpc.ilyama.golain.io` | Unary invoke, SSE stream, enqueue |

Invoke / stream / enqueue have **no** `/core/api/v1` prefix. The playground switches server URL per operation.

## Auth

| Header | Value |
|--------|-------|
| `Authorization` | `Bearer {oidc_access_token}` |
| `ORG-ID` | Active organization UUID |

Unary invoke and enqueue also need `Connect-Protocol-Version: 1`. Streams need `Accept: text/event-stream`.

See [Authentication](/api-reference/authentication).

## Permissions

| Operation | Permission |
|-----------|------------|
| List services, audit, poll queued, invoke, stream, enqueue | `can_invoke_rpc` on device |
| Reflect schema | `can_write_device_metadata` on device |
| Get project descriptor | Project-scoped read |

## Endpoints in the playground

### Management (`api.ilyama.golain.io`)

| Method | Path |
|--------|------|
| `GET` | `/projects/{project_id}/devices/{device_id}/rpc/services` |
| `POST` | `/projects/{project_id}/devices/{device_id}/rpc/reflect` |
| `GET` | `/projects/{project_id}/devices/{device_id}/rpc/sessions/{session_id}/invocations` |
| `GET` | `/projects/{project_id}/devices/{device_id}/rpc/queued` |
| `GET` | `/projects/{project_id}/devices/{device_id}/rpc/queued/{call_id}` |
| `GET` | `/projects/{project_id}/rpc/descriptors/{descriptor_id}` |

### RPC proxy (`rpc.ilyama.golain.io`)

| Method | Path |
|--------|------|
| `POST` | `/projects/{project_id}/devices/{device_id}/{service}/{method}` |
| `POST` | `/projects/{project_id}/devices/{device_id}/streams/{service}/{method}` |
| `POST` | `/projects/{project_id}/devices/{device_id}/enqueue/{service}/{method}` |

## Rate limits

| Surface | Approx. limit |
|---------|---------------|
| Management routes | 12–64 req/s (varies by endpoint) |
| Sync invoke (RPC host) | 32 req/s |
| Enqueue (RPC host) | 12 req/s |

Back off on `429`, `502`, and `503`.
